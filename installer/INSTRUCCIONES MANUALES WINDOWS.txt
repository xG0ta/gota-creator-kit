GOTA CREATOR KIT — PREMIERE 2026 SIN CREATIVE CLOUD

Este ZIP reúne todo lo necesario para instalar Gota Creator Kit cuando
Creative Cloud no está disponible. Extrae todo antes de usarlo.

1. Ejecuta GotaCreatorKit-<versión>-Windows.exe.
   Es indispensable: instala el motor local de Reencuadre, eliminar silencios,
   subtítulos, Biblioteca Gota y licencias.

2. Instala "Gota Creator Kit.ccx" con un gestor compatible con CCX.
   Este paso añade el panel a Premiere 2026 cuando Creative Cloud no funciona.

3. Abre Premiere y entra a Ventana > Plugins de UXP > Gota Creator Kit.

IMPORTANTE
El archivo CCX agrega el panel, pero el EXE instala el motor local. Instala
ambos para que todas las herramientas funcionen.
